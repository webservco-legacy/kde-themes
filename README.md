# kde-themes

My KDE 3 desktop of 2007, published on kde-look.org: ubTheme (a KDE theme), ublook (a SuperKaramba look with a clock,
system monitors and an Amarok player) and ubColorScheme (a colour scheme), with two screenshots of 2008. A historical
archive, kept read-only: for KDE 3, not maintained.

## History

| Date | Commit | |
|---|---|---|
| 2007-10-08 | ef202d4 | ubTheme 0.1, ublook 0.1 and ubColorScheme 0.1, the three packages expanded |
| 2008-03-23 | 4401b5b | two screenshots |

Left out of the whole history: the sound files of the theme, and the theme's package file `ubTheme.kth`, which bundles
them. The theme's `ubTheme.xml` still names them. The desktop wallpaper NIGHT is by another author (kde-look.org).

## How it was built

From a tarball of my Linux folder, turned into git in 2026 (3 commits), dated by the files. The last commit
before this README sets LF line endings.
